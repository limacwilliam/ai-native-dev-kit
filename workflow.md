# Delivery workflow

| Stage | Human responsibility | AI assistance |
|---|---|---|
| Spec | Define outcome, constraints and acceptance | Identify ambiguity and draft artifacts |
| Plan | Choose trade-offs and approve scope | Break work into verifiable tasks |
| Build | Own architecture and merge decisions | Generate bounded implementation candidates |
| Verify | Review security and business behavior | Draft tests; find edge cases |
| Operate | Approve runbook and incident decisions | Summarize telemetry and incident evidence |

Release only when the definition of done is satisfied.
